# Digital Literacy

This project is **for knowledge sharing only** about digital literacy for end users. This repo is public.

## What's Inside

| Folder | Description |
|--------|-------------|
| `slide/` | Slidev presentation for a 3-hour Digital Literacy Training workshop |
| `phishing-demo/` | Next.js phishing awareness demo (fake Google & Facebook login pages) |

## Disclaimer

This repository is strictly for **educational and training purposes**. The phishing demo simulates fake login pages to teach end users how to recognize phishing attacks. It is **not intended for malicious use**. No real credentials should be entered — every demo page displays a prominent warning banner.

## Getting Started

### Slides

```bash
cd slide
pnpm install
pnpm dev
```

### Phishing Demo

```bash
cd phishing-demo
pnpm install
pnpm dev
```
